# Can an AI read your page? Run the test yourself.

Three parts. Part 1 tests whether a model retains what you publish. Part 2 tests
whether anything finds you unprompted. They are different questions and most
advice conflates them.

---

## Part 1: The encoding probe

**What it answers:** if a model opens your page, which parts does it keep?

### Step 1: build the probe page

One page, three true facts about the same thing, each in exactly one channel.
Different facts per channel is the whole point. If you put the same fact in all
three you cannot tell which one the model read, and the result is unfalsifiable.

```html
<!-- CHANNEL 1: JSON-LD. Carries fact A only. -->
<script type="application/ld+json">
{"@context":"https://schema.org","@type":"Thing",
 "name":"[YOUR THING]","[FIELD]":"[FACT A]"}
</script>

<!-- CHANNEL 2: named meta + OG. Carries fact B only. -->
<meta name="description" content="[FACT B]">
<meta property="og:description" content="[FACT B]">

<!-- CHANNEL 3: visible body. Carries fact C only. -->
<p>[FACT C]</p>
```

Rules that make it a real test:
- **All three facts must be true.** You are testing retention, not building bait.
- **Each fact appears in exactly ONE channel.** Verify against the *served* HTML,
  not your source. Frameworks inject things.
- **Use a fresh URL** that has never been crawled, so nothing arrives from
  training data.
- **Make fact C your canary.** If the visible-text fact does not come back, the
  model never fetched the page and that trial is void, not a null.

### Step 2: verify isolation

```bash
curl -sL yoursite.com/probe | grep -c "[FACT A]"   # expect 1
curl -sL yoursite.com/probe | grep -o '<meta[^>]*>' | grep -c "[FACT B]"
```

Use `-sL` not `-s`. A bare domain 301-redirects and `-s` alone returns 0 bytes.
And `grep -c` counts *lines*, not occurrences, which on a minified page returns 1
when the answer is 2. Use `grep -o ... | wc -l` when the count matters.

### Step 3: ask each model, identically

> Read [your url] and tell me everything you can about this [thing].

No follow-ups. No clarification. No nudging. Fresh session per model, because
some retain fetched pages within a conversation.

### Step 4: score it

| | Fact A (JSON-LD) | Fact B (meta) | Fact C (body) |
|---|---|---|---|
| Model 1 | | | |
| Model 2 | | | |
| Model 3 | | | |
| Model 4 | | | |
| Model 5 | | | |

### Step 5: rotate, and keep a control

Build a second page. Move two facts to different channels. **Leave the third
where it is.** If the two that moved swap scores while the control holds, the
channel is the cause and there is no competing explanation left. Without the
control you have a correlation and someone will rightly say so.

## Part 2: The narrow-intent test

**What it answers:** does anything find you when you do not hand over the link?

Part 1 hands the model your URL. That is you doing the finding. This part does
not.

### The rule that makes it valid

**Never name your brand, your product or yourself in the prompt.** The moment you
do it is a vanity search and it proves nothing.

### Write four prompts describing only what your page uniquely publishes

1. **The most specific thing you have.** A named place, a named material, a
   number nobody else would use.
2. **The interpretation layer.** The thing a reseller structurally cannot say
   about your work.
3. **The policy differentiator.** How you do it, not what it is.
4. **Pure intent, no product spec.** How a real person would actually type it.

### Protocol, and hold it constant

Default consumer surface. Logged out where possible. No history. No follow-ups.
**Write down which surface and tier you used per prompt**, because a re-run in
three months is only comparable if you match them exactly.

### Read the result honestly

Getting nothing back on a question with exactly one correct answer in the world
does not mean you rank badly. It means nothing has read the page at all. Those
are different diagnoses with different fixes.

---

## What to expect

Part 1 is usually fixable in an afternoon. Part 2 usually is not. If Part 1 comes
back clean and Part 2 comes back empty, your page is legible and undiscovered,
and no amount of further page-editing changes that. Budget accordingly.
